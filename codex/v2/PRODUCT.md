# 两个人的空间

四套独立、手机优先的完整情侣空间交互原型，由用户确认实施。样例中的阿澄、小满及全部经历均为虚构；不使用上一个版本或 `doc` 中的私人内容。

| 空间 | 核心任务 | 完整流程 |
|---|---|---|
| 同频 | 共同生活安排 | 心情和便笺、日历约定、愿望安排与完成、双方资料 |
| 余温 | 收藏照片与心事 | 相册、回忆上传与编辑、时间档案、草稿与本机投递信件 |
| 小屋 | 照料和布置共同的家 | 场景区域探索、植物照料、冰箱留言、三处装饰、昼夜灯光 |
| 心动游乐场 | 创造共同体验 | 三题双人作答与交接、结果票根、约会抽签、计划与感想 |

范围是可用原型，无账户、后端、远程消息和跨设备同步。用户可切换本机角色，双方答案均由体验者输入。保存成功才关闭编辑器，失败保留输入。原型的本地角色区分不构成账号安全隔离。

每套保留自己的视觉、导航、页面组件及数据模型。共同基础只包含持久化、图片处理、对话框焦点行为。四套数据独立存放在 IndexedDB `two-of-us-v2` 的 `documents` 命名空间；图片在同库 `images` 中按空间前缀隔离。编辑草稿存在当前浏览器 localStorage。重置只影响被选中的空间。

同频完成愿望会同步其关联约定；全部关联约定完成后愿望才完成。重新开启一个约定会重新开启其愿望。删除愿望保留日历约定。余温删除相册保留回忆，已投递信件不可编辑。游乐场的历史票根保存当时快照，再次赴约会留下新票根。

本实现位于 `codex/v2`，原版本不变。没有服务器 API 或外部内容请求。
