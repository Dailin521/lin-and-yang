# 素材说明

本版复用 `codex/v2/public/assets/` 内已经由内置 imagegen 生成的三张虚构摄影素材：

- `coast.png`：远景中的虚构成年情侣与海岸。
- `train.png`：列车窗边、旅途和牵着的手。
- `morning.png`：两杯咖啡与清晨餐桌。

没有真实人物资料，没有外部图片链接。完整生成提示保留在 `../v2/ASSETS.md`。没有复制小屋、植物和装饰资源。

星空、流星、星尘、光晕、轨道、照片星球均由 Canvas 和 CSS 实现。图标使用 Lucide；所有文字和操作控件都是可交互的真实界面。

本地字体为 Noto Sans SC 400/700、Noto Serif SC 500。OFL 许可证与中文子集一起放在 `public/fonts/`。字体来自对应的 `@fontsource` npm 包。
